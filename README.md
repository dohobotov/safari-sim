# Дикая Долина — 3D Сафари-Экосистема

Автономная браузерная 3D-симуляция жизни дикой природы на Three.js.

## Обитатели и биомы

- **Саванна** (западный берег): слоны, львы, жирафы, зебры, антилопы, падальщики-грифы и пересыхающие в засуху водопои.
- **Река и броды**: бегемоты (днюют в воде, ночью выходят пастись на берега) и три мелководных брода, расширяющихся в сухой сезон.
- **Джунгли** (восточный берег): одиночные тигры, лесные олени и кабаны.

## Управление камерой

- **ЛКМ + перетаскивание** — вращение камеры
- **ПКМ + перетаскивание** или **WASD / Стрелки** — перемещение по долине
- **Колесо мыши** — приближение и отдаление
- **Клик по животному** — открыть документальную карточку и следовать за ним (`Esc` — отпустить)
- **Пробел** — пауза / возобновить
- **D** — режим «Авторежиссёр»
- **M** — природный звук (Web Audio API)
- **H** — скрыть / показать интерфейс (режим кинотеатра)

## Локальный запуск

```bash
npm install
npm run dev
```
